# 📊 Customer Churn Prediction System

A full-stack Machine Learning system that predicts customer churn using telecommunications customer data.

The project combines SQL databases, TensorFlow deep learning, model evaluation, and an interactive Streamlit dashboard.

---

## 🎯 Problem Statement

Customer churn is a major challenge for subscription-based businesses.

The goal is to identify customers who are likely to leave the service so that retention strategies can be applied before churn occurs.

## ▶ How to Run

### 1. Install dependencies

pip install -r requirements.txt

### 2. Create database

python sql/create_database.py

### 3. Train model

python src/train_tensorflow.py

### 4. Evaluate model

python src/evaluate_model.py

### 5. Launch dashboard

streamlit run app.py
